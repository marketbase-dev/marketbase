## Why this exists

MarketBase is dual-licensed: BUSL 1.1 for everyone, plus commercial licenses
sold by Impact 11, LLC. Offering both requires holding the rights above to
every line in the project.

Without a CLA, a single contributor could block a relicense for everyone,
including the automatic conversion to Apache 2.0 that this project promises. If
you are not comfortable with these terms, open an issue describing the idea
instead and we can implement it independently.
